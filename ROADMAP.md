# Roadmap

This file lists what is planned and what has been decided against. It is not a promise of dates. Ideas go to [Discussions](https://github.com/ohallord/media-manager/discussions) first. Accepted work gets an issue.

## Vision

One self-hosted place to see, clean up, and shrink a movie and TV library. It works alongside the *arr stack and media servers rather than replacing them.

## Planned

No new features are planned. Bug fixes and dependency updates continue.

## Not planned for now

These were considered and deliberately left out. A pull request for them will likely be closed unless the decision changes here first.

- **Approval step for requests.** Any logged-in user can add a title to Radarr or Sonarr straight away. A pending-approval queue may come later.
- **Unattended library pruning.** The Library Cleanup Wizard suggests deletions, but a person reviews and confirms each one. A scheduled job that deletes without that review would need an agreed policy first.
