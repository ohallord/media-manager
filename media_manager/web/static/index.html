Where things are

The top bar is Library, Find, Requests, Calendar, Help, and Admin for operators. On a phone those links sit on a bar at the bottom of the screen. Household accounts do not see Admin.

  • Find holds Search, Coming Soon, and Trending.
  • Admin holds Setup, Paths, Users, Playback, Downloads, Duplicates, Cleanup, H.265, and Logs.

Search & add a title

  1. Open Find, then Search.
  2. Choose Movies or TV Shows.
  3. Type the title and pick the correct year / poster.
  4. Confirm add. Leave Grab now checked if you want it to start downloading immediately.

Any signed-in user can add. There is no extra approval step.

Re-download a title that will not play (TV / Colt’s TV, etc.)

Use this when a movie is already in the library but a TV or app cannot play it (bad encode, Dolby Vision Profile 5, and similar).

  1. Open Find, then Search. Choose Movies (or TV if it is a series).
  2. Search the exact title.
  3. On the result you already have, tap Search & Redownload and confirm.
  4. If nothing new downloads, Radarr may think the current file is “good enough.” Delete that file on Library first, then Search & Redownload again.
  5. An operator watches Admin → Downloads until it finishes, then refresh the TV app / library.

Share this section: https://media.example.com/#help/redownload

My Requests & Downloads

My Requests lists titles you added and whether they are still requested, downloading, or already in the library.

Downloads is under Admin. It shows SABnzbd (NZB job), Syncthing, and Radarr/Sonarr import (grab → file on disk). Those are different stages — the NZB can finish while Radarr is still importing.

Calendar vs Coming Soon vs Trending

  • Calendar — upcoming dates for titles already in Radarr/Sonarr (episode air dates, movie digital dates).
  • Coming Soon — new theatrical movies and new TV series premieres in the next 30–120 days (from TMDb).
  • Trending — popular right now, any release date.

Tap a poster for details, trailer, cast, and More Like This.

Library & duplicates

Library is everything scanned from disk. Filter by Movies/TV, resolution, or letter. Rescan Library walks the folders again.

Duplicates is under Admin. It groups extra copies and highlights the higher quality score (TRaSH-style). Deleting a worse copy is manual — the app does not auto-wipe extras.

Account

  • Change password or add a passkey with Password next to your name.
  • Theme: Light, Dark, or System in the top bar.
  • Forgot password only works if an admin configured email (SMTP).
